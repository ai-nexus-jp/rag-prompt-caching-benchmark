# 全社統合情報セキュリティ・クラウド運用・AIガバナンス業務規定マニュアル (v4.2)

文書管理番号: SEC-POL-2026-GLOBAL-001  
制定日: 2022年4月1日 / 最終改定日: 2026年10月1日  
所管部門: コーポレートIT統括本部・最高情報セキュリティ責任者（CISO）室

本規定は、当社およびグループ各社におけるすべての役員、正社員、契約社員、派遣社員、ならびに業務委託先パートナーが、社内情報資産・クラウドインフラストラクチャ・業務システム・生成AI基盤を利用および運用する上で遵守すべき標準ルールと技術的統制基準を定めたものである。すべてのシステム設計および運用オペレーションは本規定に準拠しなければならない。

## 第1章：情報資産の機密区分と取扱基準（規定コード: POL-SEC-001）

### 1.1 基本方針および適用範囲
情報資産は、Class-A（極秘・個人情報・認証鍵）、Class-B（社外秘・未公開財務情報・設計書）、Class-C（社内限・業務手順書）、Class-D（公開情報）の4段階に分類し、保存・転送・廃棄の各ライフサイクルにおける暗号化およびアクセス制御を義務付ける。
本条項は、全社クラウド基盤（Production / Staging / Development 環境）およびオンプレミス連携ネットワークのすべてのワークロードに適用される。各システムオーナーは四半期ごとに遵守状況を自己点検し、証跡ログをコンプライアンス管理ポータルへ提出しなければならない。

### 1.2 技術的統制パラメータおよび運用基準値
- **統制管理ID**: CTRL-001-A / 監査優先度: HIGH / 自動コンプライアンスチェック: ENABLED
- **暗号化・通信要件**: TLS 1.3以上（暗号スイート TLS_AES_256_GCM_SHA384 推奨）、証明書有効期限90日以内の自動ローテーション。
- **監視・アラート閾値**: 異常検知メトリクスがベースラインの3シグマを超過した場合、5分以内にPagerDuty経由でオンコール担当者へ通知。
- **例外申請プロセス**: 技術的制約により本基準の即時適用が困難な場合は、代替統制（Compensating Controls）を明記したリスク受容申請書を提出し、CISOおよび担当役員の承認を得ること。例外承認の有効期限は最大90日間とし、恒久的な適用除外は認めない。
